# Покупки из Китая

Небольшой список покупок в одном HTML-файле. Для каждой позиции можно указать цену в CNY или KZT, важность, отметить покупку, закрепить позицию и изменить её позже. Приложение показывает цену в обеих валютах по заданному вручную курсу.

## Запуск

Откройте `index.html` в современном браузере. Сборка, сервер и установка зависимостей не нужны.

## Как пользоваться

- Укажите название, положительную цену, валюту и важность; нажмите `+` или Enter.
- Измените курс вверху страницы. Он задаёт количество KZT за 1 CNY и применяется ко всем пересчитанным ценам.
- Выберите сортировку по важности или вручную. В ручном режиме перемещайте позиции мышью либо кнопками ▲ и ▼ (они также доступны с клавиатуры).
- Отмечайте купленные позиции флажком, закрепляйте значком 📌, редактируйте через ✎ и удаляйте через ×. Купленные и закреплённые позиции образуют отдельные группы; ручное перемещение действует внутри своей группы.

Данные и курс хранятся в `localStorage` текущего браузера. Они не синхронизируются между устройствами и могут исчезнуть при очистке данных сайта или в приватном режиме. Курс вводится пользователем; автоматической загрузки валютного курса нет. При блокировке хранилища изменения останутся только до перезагрузки страницы.
